# @mavna/widget

The Mavna transfer flow as one React component: bring funds from other chains to Stellar.

Part of [Mavna](https://mavna.app), which moves money from other chains onto Stellar and shows what
arrives before anything is sent. The packages build transactions for your wallet to sign; none of
them holds a key.

## Install

```sh
npm install @mavna/widget
```

Import the stylesheet once, then render the component:

```tsx
import "@mavna/widget/widget.css";
import { MavnaWidget } from "@mavna/widget";
```
