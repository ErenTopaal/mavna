# @mavna/adapter-layerzero

LayerZero OFT as a Mavna rail: USDT0 to Stellar.

Part of [Mavna](https://mavna.app), which moves money from other chains onto Stellar and shows what
arrives before anything is sent. The packages build transactions for your wallet to sign; none of
them holds a key.

## Install

```sh
npm install @mavna/adapter-layerzero
```
