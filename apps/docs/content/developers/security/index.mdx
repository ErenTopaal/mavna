# Security

This software moves other people's money across systems where most mistakes cannot
be undone. The [security model](/developers/security/model) sets out the properties
it holds, each meant to be verified by reading the code rather than trusting a
paragraph. If you find something that contradicts them,
[report it privately](/developers/security/reporting).
