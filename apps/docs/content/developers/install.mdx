# Install

The packages are a pnpm workspace you build from a checkout. You run the SDK, the
app, the sponsor, and the examples from one repository, wired together by the
workspace.

## Requirements

- Node 24.19.0. The version is pinned in `.nvmrc`, and Node 24 runs TypeScript
  directly, so the example below has no build step between the file and the
  output.
- pnpm 11.21.0, the package manager the workspace declares.

## Build it

```sh
git clone <repository> mavna
cd mavna
pnpm install
pnpm build
```

`pnpm build` runs every package's build through Turbo. Each package emits ESM to
its own `dist/` with bundled types. The workspace resolves `@mavna/core`,
`@mavna/routing`, and the rest to those builds, which is how the example and the
app import them.

## Run a quote

From the checkout, with any Stellar address, including one that does not exist
yet:

```sh
node apps/docs/examples/quote.ts GBD4SMJWOYPPTVSRUK7J5M3JHHOOIEUMWYGQOLHVHUDL4ZN2ESE3BJYA 25 ethereum-sepolia
```

This talks to the live test network: the fee comes from Circle and the
destination is read off Stellar. The [quickstart](/developers/quickstart) walks
through the file.

## Run the whole thing

The app and the sponsor come up together from the repository root:

```sh
SPONSOR_SECRET_KEY=S... docker compose up
```

The app serves on `http://localhost:4319` and the sponsor on
`http://localhost:8787`. The [sponsor service](/developers/sponsor) covers what
that key can do and every variable the compose file reads.
