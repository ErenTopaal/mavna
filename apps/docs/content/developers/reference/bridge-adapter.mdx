# The adapter contract

A rail is one package that implements `BridgeAdapter`. Nothing in the interface
names a specific bridge, chain, or SDK, so adding a rail requires no change
anywhere else. The declarations below are the real lines from `@mavna/core`.

## BridgeAdapter

`quote` returns a route or a rejection, and returning a rejection is the normal,
preferred outcome over throwing. `buildTransactions` builds, never signs, never
submits. `recover` is the one optional member.

## What a build returns

The payload is opaque to the SDK; the wallet knows how to read it. `describes` is a
sentence for a person, so consent can be informed.

`buildTransactions` takes an optional second argument, `{ sender }`, the connected
source wallet. Most rails ignore it. A rail whose service must be told where a
refund goes before it hands out a deposit address, such as
[NEAR Intents](/developers/rails/near-intents), refuses to build without it.
