# Reference

This section is generated from the source before every build. The export lists come
from each package's `src/index.ts`, and the type definitions are the exact lines
from the files that declare them, comments included. A page here can only show what
the code currently says.

- [Packages](/developers/reference/packages): every export of every package.
- [Core types](/developers/reference/core-types): the money, route, and execution
  models.
- [The adapter contract](/developers/reference/bridge-adapter): the interface a rail
  implements.
