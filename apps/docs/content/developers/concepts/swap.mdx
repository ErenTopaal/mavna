# Arriving as another asset

A rail delivers what it carries: CCTP delivers USDC. When a user wants to arrive
holding XLM, or any asset other than the one bridged, a swap leg converts it on
Stellar, and the conversion is one step in the same flow rather than a bridge
followed by a manual trade.

## The mechanism

`@mavna/swap` puts swap providers behind one `SwapProvider` interface. The one
that executes on the test network is the Stellar DEX: a classic path payment is a
single operation the network itself routes, and it needs no extra contract.

`SdexProvider.quote` asks Horizon for a strict-send path and returns the amount
out, the minimum out after slippage, and the venue. `buildPathPayment` builds the
`pathPaymentStrictSend` operation with the user's own account as both source and
destination, spending the arrived asset and receiving the wanted one, with the
minimum as a hard floor. If the market has moved past that floor the operation
fails whole, and the user keeps the asset that arrived. That is the safe direction
to fail. Slippage is applied by rounding the minimum down with integer math, never
through a float.

Two more providers exist for mainnet, where more venues are available:
`SoroswapProvider` (which needs a server-side API key) and `AquariusProvider`
(which routes through Soroban pools and can deliver to a contract).
`selectSwapProvider` prefers Soroswap when a usable key is present and falls back
to Aquarius otherwise.

## How it attaches to a route

In `@mavna/routing`, `attachSwapLeg` runs after a rail quotes. It prices the
conversion, rewrites the route's `receives` and `receivesAtLeast` to the wanted
asset, appends a `swap` step, adds its time to the estimate, and adds one to the
signature count, because the user signs the conversion themselves. If the exchange
cannot quote the conversion, the whole route comes back as a `no-liquidity`
rejection with a reason, rather than a route that cannot complete.

To the user, "send USDC, receive XLM" is one quote and one flow.
[As a user, arriving as XLM](/guides/receive-xlm) is a single toggle.
