A rail is one package that implements `BridgeAdapter`. Nothing in the interface names a bridge, a
chain or another SDK, so a new rail needs no change elsewhere: pass it to `raceAdapters` with the
others. The declarations below are copied from `packages/core/src/adapter.ts` when this site is
built.

## BridgeAdapter

`quote` returns a route or a refusal; a refusal is a normal answer, not an error. `buildTransactions`
builds and never signs or submits. `status` reads where a transfer is. `recover` and `quoteCompose`
are optional.
