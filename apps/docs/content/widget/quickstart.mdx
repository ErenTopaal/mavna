# Widget quickstart

`@mavna/widget` is a workspace package, built from a checkout alongside the SDK it
uses; [Install](/developers/install) covers building the workspace. React 19 is a
peer dependency.

## The one line that is easy to miss

```ts
import "@mavna/widget/widget.css";
```

Once, anywhere in your app. The build extracts the stylesheet into a file of its own
and strips this import from the emitted JavaScript, so importing only the component
renders every state completely unstyled and throws nothing: no error, no warning, no
console entry. It looks like a broken component rather than a missing import. In
development the widget warns about it, by reading back a custom property that only
the stylesheet defines; that check compiles away in production.

One component and one config object. `integrator` is the only required field; it
identifies you and attributes an [integrator fee](/widget/configuration) if you set
one. The network defaults to the test network.

The `sponsorUrl` above points at a sponsor you run. Its default is a local
development sponsor (`http://localhost:8787`), so [zero-XLM
arrival](/developers/concepts/sponsorship) to brand-new accounts works out of the box
only against a local sponsor: point it at your own [sponsor
service](/developers/sponsor) for production.
